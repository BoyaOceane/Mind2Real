## 2. 测试场景

### Test 1 — 数据模型初始化

| 操作 | 预期 | 结果 |
|------|------|------|
| 开新故事→打开 story.html | `styleProfile` 初始化为空结构 | ⏸ |
| 打开有旧数据的 story（无 `original`） | `migrateHistory` 回填 `original` | ⏸ |
| 新段落生成 | `history[].original` 与 `content` 一致 | ⏸ |

### Test 2 — 段落编辑 UI

| 操作 | 预期 | 结果 |
|------|------|------|
| 点击段落"润色"按钮 | 进入编辑态，左右两栏（原稿/改稿 textarea） | ⏸ |
| 修改 textarea 并点击保存 | 内容更新，恢复展示态 | ⏸ |
| 点击"取消" | 放弃修改，恢复展示态 | ⏸ |
| 点击"重置为原稿" | textarea 恢复为 original | ⏸ |
| 保存空改稿 | toast 提示"改稿不能为空" | ⏸ |

### Test 3 — 风格解析

| 操作 | 预期 | 结果 |
|------|------|------|
| 修改一段文字并保存 | toast 显示"文风已学习" | ⏸ |
| 检查 localStorage `styleProfile` | 字段被填充非空值 | ⏸ |
| 断网后保存改稿 | toast 提示文风学习失败，改稿仍保留 | ⏸ |

### Test 4 — 文风面板

### Test 5 — 续写注入
