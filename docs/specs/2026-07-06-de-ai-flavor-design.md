# 降低 AI 味设计文档

> 日期：2026-07-06  
> 主题：通过标点规则、用语禁忌与风格学习系统整合，降低生成文字的 AI 味。

## 背景

"即墨"项目当前生成文本（世界观、主角、故事正文）存在典型 AI 味信号：

- 标点层面：省略号/破折号堆砌，句号分布均匀，对话提示语冗余。
- 用语层面：高频出现"然而""不仅如此""某种""眼中闪过一丝""他感到愤怒"等。
- 结构层面：段落节奏雷同，每段都像清单式执行。

项目已具备：

- `index.html` 硬编码"写作铁律"。
- `story.html` 基于用户润色的风格学习系统（正面提示词 + 反面禁忌 + 改写示例）。
- `admin.html` 可编辑四个系统提示词。

## 目标

1. 在 **story.html 故事正文** 和 **index.html 世界观/主角生成** 中降低 AI 味。
2. 把标点/用语规则整合进现有 **风格学习系统** 的 `_default` 文风档案。
3. 保持改动最小，不引入新依赖，不改动用户自定义提示词。

## 方案

采用三层：

| 层级 | 作用 | 改动位置 |
|---|---|---|
| 默认风格档案 | 把规则写入 `_default` profile 的 `taboos` 和 `examples` | `story.html` 初始化逻辑 |
| 系统提示词补丁 | 每次调用前追加简洁约束 | `story.html` / `index.html` |
| 轻量后处理 | 兜底清洗：合并重复标点、替换禁用词 | `story.html` 显示前，`index.html` 展示前 |

### 3.1 标点规则

反面（不要）：

- 连续省略号（……）超过 1 处。
- 用破折号（——）做解释或停顿。
- 每段结尾标点平均分布。
- 对话提示语后加冒号+引号，如 `他说道："……"`。

正面（要）：

- 短句与长句交错，允许 1-2 个不完整节奏。
- 对话提示语极简或省略。
- 用换行/留白替代部分省略号。

### 3.2 用语禁忌与替换示例

| 模式 | 原句 | 改句 |
|---|---|---|
| 情绪直述 | 他感到一阵愤怒。 | 他把杯子攥出裂纹。 |
| 空泛修饰 | 某种不安涌上心头。 | 后颈的汗毛竖了起来。 |
| AI 转折 | 然而，门开了。 | 门开了。 |
| 堆砌副词 | 突然，刀光闪过。 | 刀光闪过。 |
| 眼睛戏 | 眼中闪过一丝冷意。 | 他没眨眼。 |
| 解释性开头 | 从某种意义上说，这个世界…… | （直接写场景） |

### 3.3 与风格学习系统整合

- 把规则作为 seed 数据写入 `_default` profile。
- `analyzeStyleDiff` 继续学习用户润色，合并新的禁忌。
- `formatStylePrompt` 自动把 taboos 拼入"反面提示词"。

### 3.4 应用范围

- `story.html`：开篇、续写、润色后再生成均生效。
- `index.html`：世界观、主角生成信息展示前经过清洗。

## 不做的事

- 不做完整语法解析器。
- 不改动用户已保存的自定义提示词。
- 不引入新依赖或新页面。

## 验证

- 浏览器 console 无 JS 错误。
- 新创建故事时，`_default` 文风中出现新增 taboos/examples。
- 生成文本中高频 AI 词出现频率下降。
