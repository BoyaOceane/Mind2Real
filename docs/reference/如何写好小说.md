核心心理对比表

读者心理需求 对比A（压抑端） 对比B（释放端） 钩子逻辑
正义需求 主角被冤枉/功劳被窃取/替人受过 真相大白/恶人打脸/沉冤得雪 越是不公，读者越想看到“还我公道”
安全需求 主角面临危险/失去风险/倒计时压力 化险为夷/绝处逢生/最后一秒得救 害怕失去 → 紧张；得救 → 爽
求知需求 谜题未解/伏笔未收/身份成谜 真相揭晓/伏笔回收/身份曝光 未知 → 好奇；知道答案 → 满足
归属需求 主角被孤立/被背叛/被误解 被接纳/被信任/真相大白后和解 孤独 → 心疼；团圆 → 暖心
道德需求 两难选择/被迫做坏事/伦理困境 找到第三条路/自我救赎/道德胜利 纠结 → 代入；解围 → 释然
掌控需求 失控/被玩弄/命运被安排 反杀/掌控局面/逆天改命 无力 → 焦虑；反击 → 解气
优越需求 恶人嚣张/小人得志/好人吃亏 恶人遭报/小人翻车/好人逆袭 不公 → 愤怒；报应 → 爽快
共情需求 主角痛苦/失去至亲/希望破灭 获得慰藉/重新振作/希望重燃 难过 → 心疼；治愈 → 温暖
创伤类型 核心感受 典型事件（通用版） 成年后的可能表现
被抛弃型 我不值得被留下。任何离开都是我的错。 主要照顾者在重要节点突然消失；被承诺“回来”却屡次失信；被送到他人处寄养；在人群中走失或被遗弃；照顾者去世后无人接替情感空缺。 极度害怕被拒绝，亲密关系中要么过度黏人要么不敢靠近；总在对方离开前先提分手；无法独处。
被忽视型 我的存在不重要。没有人真正在意我。 照顾者长期忙于工作/其他事务，很少回应情感需求；情感需求被嘲笑或打压（“哭什么哭”）；永远是被最后想起的那个；有兄弟姐妹时，资源/关注明显偏向另一方。 习惯性讨好他人；不知道怎么表达自己的需求；被人关注会感到不自在；容易被PUA。
被背叛型 信任是危险的。亲近的人会伤害我。 被信任的人出卖（秘密被公开、功劳被窃取）；被诬陷后无人相信；亲密的人为了自保而撇清关系；被利用后抛弃。 很难信任任何人；会反复测试伴侣的忠诚；对承诺有强烈的不安全感。
被控制型 我没有权利做自己。我的想法不重要。 凡事必须服从安排，否则被打骂或冷暴力；隐私被侵犯（日记被翻、房间被监控）；经济被完全掌控；择业/择偶被强行干涉。 要么极度顺从（失去自我），要么极度反叛（对抗一切规则）；做决定时犹豫不决。
被虐待型 我是坏的。我活该被这样对待。 身体虐待（被打、被罚、被体罚过度）；语言虐待（被辱骂、被贬低、被叫难听的绰号）；精神虐待（被羞辱、被嘲笑、被长期否定）。 自我价值感极低；容易吸引施虐型伴侣；对疼痛和伤害的忍耐度异常高。
被孤立型 我不属于任何地方。我和别人不一样。 转学后一直融不进去；因为某个特征（口音/外貌/家庭背景）被排挤；被小团体长期冷暴力；被最好的朋友带头孤立。 对社交场合极度焦虑；要么拼命融入（失去自我），要么彻底回避（不社交）。
目睹暴力型 世界是危险的。爱和伤害总是同时出现。 目睹父母/照顾者之间的暴力（身体或语言）；目睹亲近之人被伤害却无能为力；在暴力环境中长大，不知道“正常的关系”是什么样的。 要么重复暴力模式（成为施暴者或受害者），要么对冲突极度恐惧；不知道健康的亲密关系长什么样。
过早承担型 我没有童年。我必须永远照顾别人。 很小就要照顾生病的家人/弟弟妹妹；父母的情绪需要孩子来安抚；家中突发变故，被迫一夜长大；从没被照顾过，一直在照顾别人。 不会示弱，不会求助；在关系中永远是“照顾者”角色；容易 burnout（过度消耗后的彻底疲惫）。
失去安全型 随时可能出事。我不能放松。 童年经历过重大事故（火灾/车祸/自然灾害）；长期处于不稳定环境（频繁搬家/战乱/贫困）；家人突发重病或意外去世；自己被卷入过危险事件。 过度警觉，无法放松；有囤积/反复检查等强迫倾向；对“计划被打乱”反应极大。
身份否定型 真正的我不配被爱。我必须伪装。 因为性格特质（内向/敏感/好动）被嫌弃；因为爱好或天赋不被支持而被否定；真实的情绪表达被惩罚（“男孩子不许哭”）；因为性取向/性别认同被拒绝。 习惯性伪装成“别人喜欢的样子”；不敢展露真实的自己；内心有强烈的羞耻感。

使用说明：

· 一个角色可以有1-2种核心创伤，不要堆砌
· 创伤决定的是行为模式和情感按钮，不是角色的全部
一、角色维度（让人物立起来）

要素 说明 示例
核心创伤 角色的行为动机根源（见上表） 被抛弃型 → 不敢先说爱
表层欲望 角色嘴上说想要的东西 “我要升职”“我要复仇”
深层需求 角色真正缺的东西（通常与创伤相反） 想要被无条件接纳、想要安全感
致命缺陷 会真正害了角色（或让他吃亏）的性格弱点 太容易相信人、控制欲强、不敢拒绝
隐藏能力 关键时刻能救场的特质 过目不忘、精通某种冷门技能
恐惧清单 什么会让他瞬间破防 被当众羞辱、失去重要之人
日常细节 让角色像真人 喝咖啡不加糖、紧张时会咬指甲

二、关系维度（让读者在意人物之间的联结）

要素 说明 示例
关系定位 两人之间是什么关系 青梅竹马、宿敌、救赎者
情感债务 一方欠另一方什么（不一定是钱） 欠一条命、欠一个道歉、欠一句“我信你”
共同秘密 只有他们知道的事 一起目睹过某件事、共同掩盖过一个错误
未说出口的话 双方都知道但都不愿捅破 “我喜欢你”“那件事是我做的”
关系转折点 从A状态变成B状态的关键事件 从朋友变恋人、从信任变猜忌
权力动态 谁在这段关系里占上风 上司-下属、救赎者-被救赎者
情感钩子 读者想知道“他们最后会怎样” 能不能在一起、能不能和好、谁会先低头

三、情节维度（让读者停不下来）

要素 说明 示例
核心冲突 角色想要A，但现实给B 想留在家乡照顾母亲，但offer在外地
层层加码 问题不是一次解决，而是一个接一个 被冤枉 → 证据被毁 → 证人失踪
倒计时/时间压力 必须在X时间内完成某事 三天后婚礼、七天后还债
两难选择 选A伤B，选B伤A 救母亲还是救恋人
代价明确 做出选择要付出什么 说出真相会失去爱人、保持沉默会失去自我
意外援军 最没想到的人出手相助 宿敌递来关键证据
功亏一篑 差一点就成功了，然后功亏一篑 找到证据了，但被抢走了
反转 读者以为的“真相”是错的 以为的好人其实是幕后黑手

四、情绪维度（让读者“抓心”）

要素 说明 示例
压抑端先于释放端 让读者在“难受”里多待一会儿 被冤枉 → 等了两章才洗清
希望假动作 给读者希望，然后立刻拿走 以为找到证人了，结果证人是假的
情绪反差 上一秒笑，下一秒哭 刚告白成功，下一秒收到噩耗
延迟满足 读者想要的爽点，延后给 恶人被打脸不是现在，是三十章后
情感对照 用一件事反衬另一件事 女主被男主怀疑，但被男二无条件相信
无声的疼 不写哭喊，写细节 把手机扣在桌上、把面碗留在水池里
迟来的好 已经不需要了，对方才给 “对不起”——“没关系，我不需要了”

五、细节维度（让世界真实可感）

要素 说明 示例
感官细节 看/听/闻/触/尝 消毒水的味道、旧书的霉味
习惯动作 角色紧张/开心时的小动作 紧张时会转笔、开心时会哼歌
道具象征 某个物品承载情感 一只旧手表、一条围巾、一盆快死的绿萝
环境投射 天气/光线反映角色情绪 下雨天分手、晴空万里时被骗
对话潜台词 嘴上说A，实际意思是B “你来干什么”——“我想你了”
留白 不写出来的，比写出来的更重 对方正在输入……最后什么都没发

六、结构维度（让读者一直追）

要素 说明
钩子开头 第一句话就让读者想知道“然后呢”
章节断点 每章结束在“最想知道下文”的地方
节奏变化 紧张的章节和舒缓的章节交替
伏笔与回收 前面埋的，后面一定要挖
情感节拍 压抑-释放-再压抑-更大释放
爽点分布 小爽点每1-2章一次，大爽点每5-10章一次
结局预期 让读者大概知道会是HE/BE，但猜不到怎么到达
