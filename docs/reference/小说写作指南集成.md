# 小说写作指南集成方案

## 概述

`如何写好小说.md` 中的写作原则已作为默认提示词内置于 `admin.html`，AI 在生成故事时自动遵循。

## 实际注入分布

| 写作维度 | 注入的 Prompt | 在 admin.html 中的板块 |
|----------|--------------|----------------------|
| 世界-角色-情节联动 | `worldPrompt` | 世界观生成 |
| 角色维度（7要素 + 10种创伤详细说明） | `protagonistPrompt` | 主角生成 |
| 关系维度（7要素完整版） | `protagonistPrompt` | 主角生成 |
| 情节维度（8要素） | `storySystemPrompt` | 故事续写 |
| 情绪维度（7技法） | `storySystemPrompt` | 故事续写 |
| 细节维度（6技法） | `storySystemPrompt` | 故事续写 |
| 读者心理需求对照表（8种驱动） | `storySystemPrompt` | 故事续写 |
| 结构维度（7条原则） | `narrativeStylePrompt` | 叙事风格 |

## 各 Prompt 写作原则覆盖详情

### worldPrompt — 世界观生成

- **冲突土壤**：世界设定需天然包含阶层矛盾、资源争夺、规则不公
- **创伤来源**：世界应为角色创伤提供合理来源
- **规则演出来**：设定必须推演受益者与受害者
- **感官锚点**：气味、声音、温度

### protagonistPrompt — 主角生成

- **角色维度（7要素）**：核心创伤、表层欲望、深层需求、致命缺陷、隐藏能力、恐惧清单、日常细节
- **10种创伤类型详细说明**：每种包含核心感受、典型童年事件、成年行为表现
- **关系维度（7要素）**：关系定位、情感债务、共同秘密、未说出口的话、关系转折点、权力动态、情感钩子

### storySystemPrompt — 故事续写

- **读者心理需求八维对照表**：正义/安全/求知/归属/道德/掌控/优越/共情 → 压抑端→释放端→钩子逻辑
- **情绪维度（7技法）**：压抑先于释放、希望假动作、情绪反差、延迟满足、情感对照、无声的疼、迟来的好
- **情节维度（8要素）**：核心冲突、层层加码、倒计时、两难选择、代价明确、意外援军、功亏一篑、反转
- **细节维度（6技法）**：感官细节、习惯动作、道具象征、环境投射、对话潜台词、留白
- **写作十条铁律**（含钩子、感受优先、节奏控制、行动即人设等）

### narrativeStylePrompt — 叙事风格

- **结构维度（7条）**：钩子开头、章节断点、节奏变化、伏笔与回收、情感节拍、爽点分布、结局预期

## 维护方式

- 所有默认提示词定义在 `admin.html` 的 `defaultPrompts` 对象中
- 用户通过管理后台（admin.html）可编辑，修改保存在 localStorage `prompt_config`
- 点击「恢复默认」可回到上述预设值
- 修改默认值需直接编辑 `admin.html` 源码
