一、按“物理规律”划分
现实世界
遵循我们已知的物理法则。地球、人类、重力、时间单向。
规则世界
物理法则被某种人为或超自然规则替代。命名创世、字数守恒、时间可交易，都属于这一类。
星际世界
舞台扩展到宇宙尺度。星际航行、外星文明、殖民地、太空战争。
平行世界
与我们的世界相似但不同的另一个时空。分歧点可以是某场战争的结果、某个人的生死。
微观世界
故事发生在肉眼不可见的尺度。细胞、原子、细菌文明、意识的最小单位。
数据世界
存在形式是代码或信息。虚拟现实、意识上传、AI生成宇宙、模拟理论。
梦境世界
逻辑由潜意识支配。场景跳跃、象征意象、现实与梦的边界模糊。

二、按“时代位置”划分
古代世界
工业革命前的文明。冷兵器、农耕、帝国、神话与历史尚未分家。
近代世界
蒸汽、铁路、殖民、旧秩序瓦解。约18-19世纪。
现代世界
与我们生活的时代同步。科技、资本、信息爆炸、全球化。
近未来世界
距现在50-100年。可控的科技进步，社会结构开始松动但尚未崩溃。
远未来世界
距现在数百年至数千年后。人类可能已不是当前形态，文明可能已重启多次。
末日世界
文明崩溃进行时或崩溃后。资源匮乏、秩序重建、生存优先。
后末日世界
末日之后的新文明已稳定成型。旧世界的废墟成为神话或禁忌。

三、按“技术路线”划分
蒸汽朋克
停留在蒸汽动力时代，但技术被推向极致。齿轮、铜管、飞艇、维多利亚美学。
赛博朋克
高科技，低生活。义体改造、霓虹灯、巨型企业、雨夜街头。
柴油朋克
以内燃机和重工业为核心美学。钢铁、履带、战争机器、石油崇拜。
原子朋克
1950-60年代核能乐观主义。原子汽车、太空殖民梦、复古未来主义。
生物朋克
技术路线是基因改造和生物工程。活体建筑、器官交易、物种边界消失。
丝绸朋克
东亚古典美学与幻想技术的结合。竹木机械、风水动力、纸鹤通讯。
石器朋克
以原始材料实现超越时代的工程学。巨石计算机、骨质飞翼、燧石机械。

四、按“超自然力量”划分
无魔世界
没有任何超自然元素。一切可被理性和科学解释。
低魔世界
超自然力量存在但极其稀有。多数人一生未曾目睹，魔法是传说或禁忌。
高魔世界
超自然力量是日常的一部分。魔法被系统化研究，神明频繁干预人间。
神话世界
世界由神话逻辑支配。日月是神明的战车，雷电是宙斯的怒火，万物有灵。
克苏鲁世界
超自然力量是不可名状、不可理解的。接触即疯狂，真相即毁灭。
灵异世界
超自然力量以鬼魂、怨念、不可解释的事件形式存在。常与特定地点或物件绑定。

五、按“文明形态”划分
部落世界
以血缘氏族为基本单位。口传历史、萨满信仰、人与自然尚未分离。
城邦世界
以独立城市为国家单位。商业、公民政治、城邦间的联盟与战争。
帝国世界
广袤疆域、多民族、中央集权。皇帝、官僚体系、驿道与长城。
封建世界
土地分封、骑士与领主、层层效忠。城堡、庄园、领主私战。
资本世界
以资本和市场为核心驱动力。公司、股票、消费主义、品牌信仰。
共产世界
生产资料公有，按需分配。阶级消失，国家逐渐消亡。
无政府世界
没有中央权力。自治公社、互助网络、共识决策。
蜂巢世界
个体丧失独立意识。集体心智、分工刻在基因里、个体为整体牺牲。

六、按“存在状态”划分
物质世界
一切由物质构成，遵循唯物逻辑。
精神世界
一切由意识构成。想法改变现实，信念决定物理。
模拟世界
我们活在一个巨大的模拟器中。卡顿是系统bug，奇迹是管理员操作。
书中世界
角色知道自己在书里。页码是时间，章节是纪元，读者翻页是命运。
死后世界
故事发生在死亡之后。审判、轮回、永恒的虚空或新的旅程。
转生世界
主角带着前世记忆重活一次。预知、悔改、修正过去的错误。

七、按“异化方向”划分
废土世界
文明废墟之上。资源匮乏，弱肉强食，旧日遗物成为圣物。
异星世界
完全脱离地球生态的外星环境。硅基生命、液态思维、甲烷海洋。
深海世界
故事发生在海底。压强、黑暗、未知生物、沉没的文明。
地下世界
地表已不可居住，人类移居地下。隧道、人造光源、幽闭恐惧。
浮空世界
大地破碎，文明活在漂浮的岛屿上。飞行是生存技能，坠落是终极恐惧。
巨构世界
整个世界是一座巨大的建筑或机器。各层居民互不知晓彼此的存在。
