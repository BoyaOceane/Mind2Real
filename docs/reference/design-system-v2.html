02 · 字体

字体层级

宋体衬线用于标题与强调，醒过来无衬线用于正文阅读，楷体用于古文引用与特殊场景。三层分离，确保阅读舒适度。

Display — 宋体衬线 标题 · 大字号 · 墨色浓

05 · 阅读排版

正文排版规范

小说阅读场景的核心规范：强对比度、充足行高、合理行长、衬线标题。

正文示例 — 无装饰阅读

夜色渐深，江面泛起薄雾。画舫缓缓行驶，船头挂着两盏红灯笼，光晕落在水面上，随波纹一圈圈散开。

林霜坐在窗边，手指轻轻敲着桐木桌面，似乎在等什么。桌上摊开一本旧册，纸页已经泛黄，边角卷起了毛边。

「客官，前面就是销金窝了。」船夫的声音从甲板上传来，带着几分敬畏。

她抬起头，目光穿过蒙蒙水汽，望向远处灯火阑珊的彼岸。那里是江湖中人谈之色变的禁地，也是她此行必到之处。

阅读排版五原则：
字重分明 · 行高1.9+ · 行长不超过70字 · 段距大于行距 · 朱砂仅限点缀
