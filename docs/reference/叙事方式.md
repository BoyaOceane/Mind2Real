一、主体聚焦（谁被书写）
专业术语	对应通俗表述
人民叙事	写普通人群像
英雄叙事	写传奇个体
底层叙事	写边缘/底层人物
精英叙事	写权力/上层人物

二、认知视角（叙述者知道多少）
专业术语	对应通俗表述
全知视角	上帝视角
限知视角	单一人物视角
外视角	客观行为主义视角

三、时态视角（时间站位）
专业术语	对应通俗表述
回溯性叙事	回忆录式倒叙
共时性叙事	即时性直播感

四、叙述可靠性（叙述者是否可信）
专业术语	对应通俗表述
不可靠叙述	叙述者在撒谎/隐瞒
复调叙事	多声部平等对话

五、结构形式（叙事如何组织）
专业术语	对应通俗表述
元叙事	打破第四面墙
非线性叙事	时间线被打乱
碎片化叙事	多视角拼图还原
反转叙事	后期颠覆性翻转
