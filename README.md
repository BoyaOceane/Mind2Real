# 心笔 (mind2real)

AI 驱动的交互式故事生成器。

## 运行

直接在浏览器中打开 `index.html`

## 设置

1. 点击右上角「设置」按钮
2. 填入你的 DeepSeek API Key
3. 保存后刷新页面

## 功能

- 世界背景生成（AI）
- 主角设定生成（AI）
- 叙事风格选择
- 金手指开关
- 性别切换
- 用户偏好保存
- 历史记录
