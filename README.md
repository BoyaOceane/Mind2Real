# 即墨 (Jimo)

AI 驱动的分支叙事故事生成器。用户通过配置世界观、主角设定、叙事风格三个维度，调用 DeepSeek API 生成连贯的交互式小说。

## 运行

直接在浏览器中打开 `index.html`（点击即用，无需安装）

## 页面

| 页面 | 职责 | 入口 |
|------|------|------|
| **index.html** | 创作入口：配置故事参数，启动创作 | 首页 |
| **story.html** | 故事阅读：流式输出、侧边辅助、剧情引导 | 从 index.html 开始创作后进入 |
| **admin.html** | 提示词管理：查看/编辑各板块系统提示词 | 顶栏"提示词管理"按钮 |

## 设置

1. 在 index.html 顶栏点击「API设置」
2. 填入 DeepSeek API Key
3. 保存后即可开始创作

## 功能

### 创作入口（index.html）
- 三卡片配置：世界背景 / 主角设定 / 叙事风格
- 每个板块可选 tag（点击"自定义"展开选择面板）
- 金手指归入主角设定
- 历史记录面板（查看/加载/删除）
- 开始创作 → 跳转 story.html

### 故事阅读（story.html）
- 流式输出，实时渲染
- 右侧辅助面板：提纲 / 线索 / 人物（三 tab 切换）
- 时间线节点（按重要性着色）：红色=重点、橙色=较重要、灰色=普通
- 人物关系图（主角居中，其他角色围绕）
- 底部输入框：输入剧情方向引导后续发展
- 保存 / 导出为 txt

### 提示词管理（admin.html）
- 四个板块：世界观生成 / 主角生成 / 故事续写 / 叙事风格
- 查看 / 编辑 / 恢复默认 / 测试
